# Campus Zombie Survival

좀비 바이러스가 확산된 대학 캠퍼스에서 살아남아 **도서관 옥상**까지 탈출하는 텍스트 기반 서바이벌 게임 기획 저장소입니다.

## 게임 개요
- 배경: 좀비 바이러스가 확산된 대학 캠퍼스
- 목표: 좀비를 피해 도서관 옥상까지 탈출
- 주요 시스템: 플레이어 체력, 랜덤 이벤트, 멀티 엔딩

## 프로젝트 구조
- `game/rules.md` : 게임 기본 규칙
- `game/events.md` : 랜덤 이벤트 목록

## 게임 플레이 팁
- 체력이 50 이하라면 학생회관 매점부터 찾아 체력을 회복하세요.
- 손전등을 얻으면 강의실 좀비 무리를 피할 확률이 높아집니다.
- 공학관 옥상의 헬기 소리는 탈출 경로의 힌트입니다.
